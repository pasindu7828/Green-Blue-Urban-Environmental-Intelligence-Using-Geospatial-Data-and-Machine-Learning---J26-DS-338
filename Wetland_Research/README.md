# Wetland Research

## Project
Green-Blue Urban Environmental Intelligence Using Geospatial Data and Machine Learning

## Research Component
Urban Wetland Change Intelligence and Seasonal Waterlogging Susceptibility Mapping

## Student
IT23189430

## Study Area
Kaduwela Municipal Council, Sri Lanka

## Main Research Parts

1. Historical Wetland Change Analysis
2. Candidate Wetland Detection
3. Future Wetland Boundary Projection
4. Seasonal Waterlogging Susceptibility Mapping

## Project Structure

- `data/` - raw, intermediate, processed and model-ready datasets
- `models/` - trained models and model artefacts
- `outputs/` - maps, figures, metrics, predictions, tables and reports
- `src/` - Python implementation for the four research parts
- `scripts/gee/` - Google Earth Engine scripts used for satellite data preparation
