# Team member frontend placeholders

The Urbanization, Wetland, and River Corridor prototype implementations were intentionally removed from this frontend package at the team's request.

Each member should add their own frontend implementation in a separate feature/page area and then register only their routes in `src/App.jsx` and their navigation entry in `src/pages/common/ProjectHome.jsx`.

The existing Urban Heat component and shared/common UI should not be modified when integrating another member's component unless coordination is required for a shared file.
